
# 📊 Ecommerce Sales Dashboard (Excel)

## 🚀 Project Summary
Built an interactive **Ecommerce Sales Dashboard** in Excel to transform raw, inconsistent sales data into structured insights for decision-making

This project focuses on **data reliability, channel performance analysis, and trend identification**, simulating a real-world business reporting scenario

---

## 🎯 Problem Statement
Raw ecommerce data often contains:
- Inconsistent channel names (e.g., Amazon vs Amaazon)
- Missing or duplicate records
- Poor structure for analysis

These issues lead to **incorrect reporting and flawed business decisions**.

---

## 🧠 Solution Approach

### 🔹 Data Cleaning & Standardization
- Resolved inconsistent categorical values (channel normalization)
- Removed duplicates to prevent double-counting
- Handled missing values to improve dataset completeness
- Ensured data integrity before analysis

### 🔹 Data Transformation
- Created structured, analysis-ready dataset
- Added helper columns for segmentation
- Optimized data for pivot-based aggregation

### 🔹 Exploratory Data Analysis (EDA)
- Analyzed **channel-wise performance**
- Evaluated **monthly sales trends**
- Compared **category-level contributions**
- Identified anomalies caused by dirty data

### 🔹 Dashboard Development
- Built dynamic **Pivot Tables & Charts**
- Designed an **interactive dashboard using slicers**
- Enabled real-time filtering for business users

---

## 📈 Key Business Insights
- Clear identification of **top-performing sales channels**
- Visibility into **seasonal/monthly sales patterns**
- Category-level performance comparison for prioritization
- Highlighted how **data inconsistencies distort insights** if not cleaned

---
